## 真机测试矩阵（安装前必做）

1. 确认实际设备运行 **iOS 26 及以上**，存在支持的 rootless 注入环境、目标微信 bundle ID 为 `com.tencent.xin`。
2. macOS + iOS 26 SDK + Theos `make clean package` 全量编译；出现任一编译错误须修复，不使用静态测试代替。
3. 不同时启用旧 WCGlass；安装后默认开关全部关闭时观察微信启动、聊天、输入、拨打电话、搜索、标签栏和设置入口。
4. 通过三指三连击进入面板，读环境/候选类诊断；如需接入聊天/首页模块，先确认类名与显示层级。
5. 逐一开启：标题胶囊、首页搜索、聊天输入、导航强调色、分段导航、变形动画；验证动态字体、深色模式、横屏、VoiceOver、减少透明度/动态效果。
6. 逐项关闭开关，确认原始 tab 按钮透明度/点击、navigationItem.titleView、输入框背景、导航颜色均恢复。
7. 水印编辑器：横竖照片、多倍屏截图、窄图、超大图片、拖动/双指缩放、关闭分享、进程内存；确认导出水印的位置和预览一致。
8. 检查无 crash、自动化日志及触控阻断；在未知微信版本保持高级模块关闭。

**限制**：目前没有 Xcode/iOS SDK/Theos 设备链路。本次仅源码结构与文本回归验证，未产出已实测的 .deb。
